# Project Overview

This repository includes five internship tasks focused on UI/UX design principles, wireframing, redesign, user research, case study analysis, and landing page design.

## Task 1 – Website UI Redesign

### Objective

Analyze an existing website and redesign its interface to improve usability, visual hierarchy, navigation, and overall user experience.

### Key Deliverables

* UI Analysis
* Problem Identification
* Redesigned Interface
* Improved User Flow
* Modern Visual Design

### Skills Used

* UI Design
* Visual Hierarchy
* Color Theory
* UX Principles

## Task 2 – CineBooking Website Redesign

### Skills Used

## Task 3 – Website Wireframing

### Objective

Create low-fidelity wireframes for a travel website focusing on layout planning and content organization before visual design.
